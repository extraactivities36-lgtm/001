# Arena Survivor

A small Godot 4.x 3D arena-survival shooter prototype. It uses procedural placeholder geometry, so no extra assets are required.

## Run

1. Open `project.godot` in Godot 4.
2. Press **F6** or **F5** to run the game.
3. Click the game window to capture the mouse.

## Controls

- **WASD** — move
- **Mouse** — look and aim
- **Left mouse button** — fire
- **Esc** — release/capture mouse
- **Enter** — restart after game over

Survive as long as you can, defeat enemies to increase your score, and watch your health. This is an early prototype; models, sound, and additional weapons can be added later.
